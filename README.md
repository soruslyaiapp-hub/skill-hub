# SkillHub

The open directory of AI skills, agents, MCP servers and prompts — sorted by the job they do.

> Status: under construction. See [PLAN.md](PLAN.md) for the roadmap and progress.

## Quick start

```bash
npm install
npm run dev
```

Open http://localhost:3000.

## Scripts

| Command | What it does |
|---------|--------------|
| `npm run dev` | Start the dev server |
| `npm run build` | Production build |
| `npm run lint` | ESLint |
| `npm run typecheck` | TypeScript check |
| `npm test` | Unit tests (Vitest) |
