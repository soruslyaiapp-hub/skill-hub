**Claude YouTube Editor** is a full pipeline from raw recording to upload. **Remotion Agent Skills** teach the agent to write clean video code, which that pipeline builds on. For 3D, **Blender MCP** drives Blender from a prompt. For UI work, **Figma Context MCP** gives the agent real layout data instead of screenshots.
