Pick **one** method first: **Superpowers** or **ECC**. They overlap, so start with one and learn it well. Add **Claude-Mem** so sessions remember each other, **Context7** for current library docs, and **Playwright MCP** so the agent can check its work in a browser. When you repeat a task often, turn it into your own skill with **Skill Creator**.
