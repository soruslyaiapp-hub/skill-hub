## What it does

A Claude Code plugin marketplace from Trail of Bits. Its skills support AI-assisted security analysis, testing and audit workflows.

## Why it is useful

- Brings structured security methods into everyday code review.
- Codex can load the same marketplace.

## How to use it

```bash
/plugin marketplace add trailofbits/skills
```

Then open `/plugin menu` and install the skills you need.

- The content uses the CC-BY-SA-4.0 license. Keep the attribution if you share or adapt it.
