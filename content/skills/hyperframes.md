## What it does

You write HTML and it renders video. HyperFrames turns HTML, CSS, media and seekable animations into MP4 files that come out the same every time.

## Why it is useful

- The skills teach your coding agent the animation and timing model, so it can actually make videos.
- Preview in the browser with live reload, then render.

## How to use it

```bash
npx skills add heygen-com/hyperframes
npx hyperframes init my-video
```

## Watch out for

- Rendering long videos takes time and CPU.
