## What it does

Firecrawl turns websites into clean data for agents. It scrapes any URL into Markdown, JSON or screenshots, crawls whole sites, batch-scrapes thousands of URLs, and can interact with pages.

## Why it is useful

- It handles JavaScript rendering, proxies and rate limits for you.
- One API for search, scrape and crawl.

## How to use it

Get an API key and call the API, or use the CLI and agent onboarding in the README. For MCP clients, see the separate Firecrawl MCP entry.

## Watch out for

- The hosted API is paid beyond the free credits.
