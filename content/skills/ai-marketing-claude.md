## What it does

A set of marketing skills for Claude Code. Point it at a website and it can audit the marketing, generate copy, build email sequences and ad campaigns, plan content calendars, study competitors and write a PDF report.

## Why it is useful

- Parallel subagents run the audit from several angles at once.
- The output is client-ready, which suits freelancers and small agencies.

## How to use it

Run the install script from the README, then type `/market` in Claude Code to see the commands.

## Watch out for

- Read install scripts before you pipe them into bash.
- Audits are a starting point. Check claims about competitors before a report goes to a client.
