## What it does

A pack of 25 skills that encode the workflows, quality gates and practices senior engineers use, from test-driven development to code review. Slash commands cover the full cycle: /spec, /plan, /build, /test, /review and /ship.

## Why it is useful

- Agents stop skipping steps, tests and review.
- You can install one skill or the whole pack.

## How to use it

```bash
npx skills add addyosmani/agent-skills
```

Add `--list` to browse first, or `--skill <name>` to install one.

## Watch out for

- More process means more tokens. Use the full flow for real features, not typo fixes.
