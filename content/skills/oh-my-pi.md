## What it does

oh-my-pi is a terminal coding agent, forked from Pi, with IDE features built in rather than bolted on. For example, renames go through the language server, so re-exports and aliased imports update too.

## Why it is useful

- Fewer broken refactors than agents that edit text blindly.
- Includes Python, a browser and subagents out of the box.

## How to use it

```bash
brew install can1357/tap/omp
```

An install script is also in the README.

## Watch out for

- It moves fast. Pin a version for team use.
