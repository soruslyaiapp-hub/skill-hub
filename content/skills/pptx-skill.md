## What it does

Use it any time a `.pptx` file is involved: create pitch decks and presentations, edit existing slides, or pull the text out of a deck.

## Why it is useful

- You get a real deck you can open in PowerPoint or Keynote.
- It also handles `.potx` templates, so new slides can match your house style.

## How to use it

```bash
/plugin marketplace add anthropics/skills
/plugin install document-skills@anthropic-agent-skills
```

## Watch out for

- Review layout and spacing by eye. Generated slides can look crowded.
