## What it does

Claude Code understands your codebase and takes action through natural language. It runs routine tasks, explains complex code and handles git workflows, without you switching context.

## Why it is useful

- Works in your terminal, in your IDE, and on GitHub when you tag @claude.
- Most of the skills on SkillCurio plug into it.

## How to use it

Install it with the script above (Homebrew also works), then run `claude` in your project folder.

## Watch out for

- It needs a Claude subscription or API credits.
- The npm install method is deprecated. Use the recommended installers.
