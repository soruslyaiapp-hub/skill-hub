## What it does

Remotion lets you make videos with React code. These Agent Skills, maintained by the Remotion team, teach your coding agent how to work in a Remotion project the right way.

## Why it is useful

- Fewer broken animations and timing bugs when an agent writes video code.
- Pairs well with pipelines such as the Claude YouTube Editor.

## How to use it

```bash
npx skills add remotion-dev/skills
```

## Watch out for

- Remotion has its own license. Larger companies need a paid company license. Check remotion.dev before commercial use.
