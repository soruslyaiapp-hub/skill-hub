## What it does

Hallmark fights the look where every AI-made UI is a colour swap of the same template. It picks a layout structure for each brief, applies one of twenty-one themes, and runs fifty-seven "slop test" checks plus a self-critique before it outputs anything.

## Why it is useful

- Two different briefs get two genuinely different layouts.
- The rules live in the skill, so you do not have to fight the default in every prompt.

## How to use it

```bash
npx skills add nutlope/hallmark
```

Then ask your agent to design or restyle a page.

## Watch out for

- It is opinionated. Read the themes before using it on an existing brand.
