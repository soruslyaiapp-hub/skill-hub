## What it does

It gives a team of agents one shared memory layer. Conversations, documents and code become four kinds of reusable memory, so agents stop re-reading docs and re-learning the codebase every session.

## Why it is useful

- Experience compounds across sessions, agents and frameworks.
- Memory is governed, not just piled up.

## How to use it

Follow the README to start the three services (memory-core, memory-hub and proxy), then connect your agents.

## Watch out for

- Team Memory is in beta and changing quickly.
